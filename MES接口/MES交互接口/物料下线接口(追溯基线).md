###### 物料下线接口(追溯基线)

**简要描述**

用于使用物料追溯基线的产品，进行物料下线的操作

**请求URL**

`http://10.200.6.27:10002/fundation/online-mes/`ml/mat/offline

对应的Webservice地址

http://10.200.6.54:10002/MatService.asmx?op=ML_MAT_MatOfflineV1

**请求方式**

POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID|String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**Body参数**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|planName |是 |string|计划||
|station|是|string|站位||
|line|是|string|线体||
|matsn|是|string|物料流水码||
|workStage|是 |int|工段 |0：贴片；1：插件；2：总装|



**返回参数说明**



|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|code|int|结果码|0：成功；其他：失败|
|msg|string|错误消息||
|||||

**请求成功示例**

|```JSON {   "planName":"PCB2405-013845",   "station": "CJ-001",   "line": "CZDIP001",   "matsn": "2403291130920294",   "workStage": "1" } ``` |
|---|

**返回示例**

|```JSON {     "succ": **true**,     "code": 0,     "msg": "",     "exceptionMsg": "",     "excuteMiniSeconds": 396,     "env": "Production" } ``` |
|---|
