###### **过站接口**

**简要描述**

该接口主要用于测试结束后，过站处理。

**请求URL**

http://10.200.6.27:10002/mes/api/station/exit/v1.0.0

**请求方式**

POST

**请求参数**

|\{ "planNo": "string", "line": "string", "station": "string", "sn": "string", "groupNo": "string", "user": "string", "result": "boolen" \}|
|---|

**参数说明**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|planNo|是|string|计划号||
|line|是|string|生产线号||
|station|是|string|站位||
|sn|是|string|主板SN|多个主板用逗号“,”分隔|
|groupNo|是|string|班组||
|user|是|string|员工工号||
|result|是|boolen|结果||

**请求成功示例**

|\{ "planNo": "ASM2310-006529", "line": "动总1线", "station": "AFA010", "sn": "210264002510Q4100031", "groupNo": "总装1班", "user": "HD001", "result": true \}|
|---|

**返回示例**

|\{ "code": 0, "message": "测试成功，请到下一站（AFA020A）测试！", "status": 200 \}|
|---|

**返回参数说明**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|code|int|错误代码|0：成功；1：失败|
|message|string|处理结果消息|-|
|status|int|状态||

注意：如果该站位存在多次判定原则，接口返回信息如下

例如:

3判1的原则（三次测试机会，需要OK一次才能过站）

第一次失败：“("第1次测试失败,需在本工序测试成功1次才能流入下一工序)”

\{

"code": 0,

"message": "第1次测试失败,需在本工序测试成功1次才能流入下一工序",

"status": 200

\}

第二次失败：“("第2次测试失败,需在本工序测试成功1次才能流入下一工序")”

能源产品提示

第三次失败：“(测试失败，请及时FA分析！)”

\{

"code": 0,

"message": "测试失败，请及时FA分析！",

"status": 200

\}

其他产品

第三次失败：“本次测试失败，请及时送修！”



3判2的原则（三次测试机会，需要OK两次）

第一次失败：“第一次失败：“(t,"第1次测试失败,需在本工序测试成功1次才能流入下一工序",HUD-SF-8)””

第二次测试成功：“本次测试成功，需在本工序再测试成功1次才能流入下一工序”

第三次测试成功：“测试成功，请到下一站（XXXX）测试！”
