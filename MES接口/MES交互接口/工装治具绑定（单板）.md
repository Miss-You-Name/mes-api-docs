###### **工装治具绑定（单板）**

**简要描述**

工装绑定。建立relationship表的绑定关系

**请求URL**

http://10.200.6.27:10002/fundation/online-mes/ml/dip/bindpalletcodes

对应的websevice接口

http://10.200.6.54:10002/DIPService.asmx?op=ML_DIP_BindPalletCodes

**请求方式**

POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID|String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**路由参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|pcbaSns|string|所有平板条码|条码按逗号分割： LD257T000013,LD257T000014|
|pallet|string|托盘号||
|planName|string|计划号|PCB2504-030029|
|line|string|线体|传line字段|
|userCode|string|用户名|admin|



**返回参数说明**



|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|code|int|错误代码|0：成功；1：失败|
|msg|string|处理结果消息|-|

**请求成功示例**

|```JSON {   "pcbaSns": "LD256SHO22985",   "pallet": "GZ-QC-20255-JZJT-009VB",   "planName": "PCB2505-031673",   "line": "xxx",   "userCode": "admin" } ``` |
|---|

**返回示例**

|```JSON {   "succ": true,   "code": 0,   "msg": "",   "exceptionMsg": "",   "excuteMiniSeconds": 8099,   "env": "Development" } ``` |
|---|
