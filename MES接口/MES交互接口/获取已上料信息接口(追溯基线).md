###### 获取已上料信息接口(追溯基线)

**简要描述**

用于涉及物料追溯基线的产品，获取已经扫描上线的物料列表清单

**请求URL**

`http://10.200.6.27:10002/fundation/online-mes/`ml/mat/getloadedmatdetail

对应的Webservice地址

http://10.200.6.54:10002/MatService.asmx?op=ML_MAT_GetLoadedMatDetail

**请求方式**

POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID|String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**Body参数**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|planName |是 |string|计划||
|station|是|string|站位||
|line|是|string|线体||
|workStage|是|string|工段|0：贴片；1：插件；2：总装|



**返回参数说明**



|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|code|int|结果码|0：成功；其他：失败|
|msg|string|错误消息||
|data|object\[\]|数据||
|data\[i\].isAccessories|int|||
|data\[i\].materialType|int|||
|data\[i\].materialMainCode|string|||
|data\[i\].materialCode|string|物料代码||
|data\[i\].matSn|string|物料流水||
|data\[i\].totalNum|decimal|总数||
|data\[i\].currentNum|decimal|当前数量||
|data\[i\].line|string|线体||
|data\[i\].showStation|string|||
|data\[i\].remark|string|备注||

**请求成功示例**

|```JSON {   "planName": "PCB2504-030565",   "station": "CJ-001",   "line": "XT000119",   "workStage": "1" } ``` |
