###### **根据工装治具查询绑定的整机(物料)条码**

**简要描述**

根据主板条码查询该条码所有拼板关系。

**请求URL**

`http://10.200.6.27:10002/fundation/online-mes/ml/ss/GetZZProductCodeWithCode`

**请求方式**

POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID|String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**Body参数**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|planName|是|string|计划号|-|
|gzCode|是|string|站位|-|



**返回参数说明**



|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|code|int|错误码|0：成功，其他失败|
|msg|string|错误信息|-|
|data|string|整机(物料)条码|-|

**请求成功示例**

|```JSON { "planName": "ASM2401-009470","gzCode": "NY-ZP-008-A01" } ``` |
|---|

**返回示例**

|```JSON {"data": "LD242Y000047","succ": true,"code": 0,"msg": "","exceptionMsg": "","excuteMiniSeconds": 2902,"env": "Development" } ``` |
|---|
