###### 拼版**过站接口**

**简要描述**

过站(通用)，过站成功，errMsg为空,codeSns可以为逗号分隔的多个主板条码

**请求URL**

`http://10.200.6.27:10002/fundation/online-mes/``ml/ss/aftertest`

对应的Webservice地址

http://10.200.6.54:10002/StationService.asmx?op=ML_SS_AfterTest

**请求方式**

POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID|String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**Body参数**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|planName|是|string|计划号|-|
|banzu|是|string|班组|-|
|line|是|string|线体|-|
|user|是|string|用户||
|station|是|string|站位||
|codeSns |是|string |过站条码，codeSns可以为逗号分隔的多个主板条码||
|result|是|bool|true:OK过站 false:NG过站||

**返回参数说明**



|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|succ|bool|true:接口调用成功 false：接口调用失败||

**请求成功示例**

```json
{
    "planName":"PCB2407-016493",
    "banzu":"test",
    "line":"test",
    "user":"test",
    "station":"1MP0",
    "codeSns":"LD253H003353,LD253H003355",
    "result":true
}
```

**返回示例**

|```JSON {   "succ": true,   "code": 0,   "msg": "成功",   "exceptionMsg": "",   "excuteMiniSeconds": 2396,   "env": "Development" } ``` |
