##### **条码锁定**

简要描述

封装二线MES锁定接口

- 二线接口地址

    - 正式：[http://10.200.6.111:8081/mes/lock/taskLock](http://10.200.6.111:8081/mes/lock/taskLock)

    - 测试：[http://10.200.6.200:8082/mes/lock/taskLock](http://10.200.6.200:8082/mes/lock/taskLock)

**请求URL**

- `正式： ``http://10.200.6.27:10002/fundation/unified/mes/task/lock`

- `测试： ``http://10.200.6.200:10002/fundation/unified/mes/task/lock`

**请求方式**

POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID|String|网关分配的应用Id|网关分配的应用id|

**Body参数**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|lockType|是|int|锁定类型：1：华为任务令 2：九州任务令 3：整机 4：单板 5：中箱|-|
|productCategory|是|string|产品类型|- |
|lockRemark|是|string|锁定原因||
|lockData|是|string|锁定值 (华为任务令、九州任务令、单板条码、整机条码、中箱号)|CCD3必须|
|lockModel|是|int|锁定方式1：质量锁定 2：NPI锁定 3：EC锁定 4:标签锁定 5：物料锁定 6:称重锁定 13：整机托盘锁定|非必须|
|souce|是|string|锁定来源（0：质量平台；1：一线MES；2：二线MES;3:doclib）||
|planName|是|string|计划||

**返回参数说明**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|code|int|错误码|0：成功，其他失败|
|msg|string|错误信息|-|

**请求示例**

```JSON
{
  "lockType": 3,
  "productCategory": "HW_HPLC",
  "lockRemark": "测试锁定",
  "lockData": "2198031704LDR2888538",
  "lockModel": 1,
  "souce": "2",
  "planName": "ASM2502-023027"
}
```

**返回成功示例**

```JSON
{
  "succ": true,
  "code": 0,
  "msg": "",
  "message": "",
  "exceptionMsg": "",
  "excuteMiniSeconds": 13007,
  "env": "Development"
}
```
