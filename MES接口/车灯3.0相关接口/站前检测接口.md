##### 站前检测接口

简要描述

根据各事业部需求，进行条件管控，包含固定工装

请求URL：

测试：http://10.200.6.200:10002`/fundation``/api/device/before/test`

正式：http://10.200.6.27:10002`/fundation``/api/device/before/test`

webservice：

COM_Device_DeviceBeforeTest

请求方式

- POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID |String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**Body参数**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|planName|是|String|计划号||
|station|是|String|站位||
|line|是|String|线体||
|scanCode|是|String|扫描条码|可能是移动工装条码，可能是产品条码|
|userCode|是|String|员工工号||
|pallet|否|String|托盘号|涉及固定工装站位使用该字段，其余不涉及固定工装不填该字段|
|isPb|是|int|扫码内容是否拼版 |0否 1是 使用场景：单板计划，想通过一个条码查询出其余所有的拼版条码|
|isMatCode|是|int|扫码内容是否精准物料|0否 1是 使用场景：用于扫码内容为物料条码时使用，其他场景传0|
|pcbasn|否 |String|采集的产品条码|如果该字段有值，则会校验接口返回的条码值是否与该字段传入值相同，校验采集条码是否一致 如果该字段为空则不进行校验 多个条码可以使用逗号分隔 210264002510Q4100031,210264002510Q4100032,210264002510Q4100033|

注意：isPb，isMatCode字段如果我司没有特殊说明，都传0

接口内执行顺序，先判断是否拼版→是否精准物料→通用检测

**返回参数说明**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|succ|否|Bool|接口状态||
|code|是|Int|错误码，0：成功；其他失败||
|msg|是|String|错误消息||
|exceptionMsg|否|String|异常信息||
|excuteMiniSeconds|否|Int|接口耗时||
|env|否|String|环境，development：开发环境，production：生产环境||
|pcbasn|是|string |返回所有条码|1、如果存在拼版关系，返回所有拼版条码 2、如果不存在平板关系，则返回当前扫描条码 3、如果扫码为移动工装，则返回工装绑定所有的条码 例如：210264002510Q4100031,210264002510Q4100032,210264002510Q4100033|

**请求示例**

```JSON
{
  "planName": "ASM2402-009527",
  "station": "HUD-F3-1",
  "line": "ONT_DIP_007",
  "scanCode": "210264002510Q4100031",
  "userCode": "41487",
  "pallet": "GZ-QC-20255-JZJT-009VB",
  "pcbasn": "XXXXXXXXX",
  "isPb": 0,
  "isMatCode": 0
}
```

**返回示例**

```JSON
{
  "succ": true,
  "code": 0,
  "msg": "",
  "exceptionMsg": "",
  "excuteMiniSeconds": 650,
  "env": "production",
  "data":[{"pcbasn": "210264002510Q4100031,210264002510Q4100032,210264002510Q4100033"}]
}
```
