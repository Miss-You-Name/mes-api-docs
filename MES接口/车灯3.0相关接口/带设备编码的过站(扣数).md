# 带设备编码的过站(扣数)

> **模块**: [[00-总览|MES接口]] > 车灯3.0相关接口
> **方式**: POST

---

##### 带设备编码的过站(扣数)

**URL：**/after/ty/ks/afterdevicecode（完整路径见 Base URL）



**完整地址**：http://10.200.6.27:10002/fundation/api/online-mes/v2/transfer/after/ty/ks/afterdevicecode



**Method：**POST



**描述：**完成某站位操作后过站，并携带设备编码。

**请求头（Headers）**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID |String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**请求体（Body）**

|参数名|类型|必填|说明|
|---|---|---|---|
|plan_name|string|是|计划名称|
|station|string|是|站位编码|
|banzu|string|是|班组名称，如 插件一班|
|line|string|是|线体编码|
|codeSn|string|是|条码/序列号|
|user|string|是|操作人员工号，如 41111|
|result|boolean|是|过站结果，true 表示合格/通过，false 表示不合格/不通过|
|workStage|int|是|工段标识|
|deviceCode|string|是|设备编码|

**请求示例**



```JSON
**{
  "plan_name": "ASM2502-022442",
  "station":"3MP2",
  "banzu":"插件一班",
  "line": "XT000012",
  "codeSn": "LD248H110270",
  "user":"1234444",
  "result":true,
  "workStage":2,
  "deviceCode":"ST-SmarX3515B0012"
****}**
```

**响应示例**

成功时：



```JSON
**{
    "data": {},
    "succ": true,
    "code": 0,
    "msg": "",
    "message": "",
    "exceptionMsg": "",
    "excuteMiniSeconds": 5711,
    "env": "Production"
****}**
```

失败时（如站位不在计划路径中）：



```JSON
**{
  "data": null,
  "succ": false,
  "code": 2,
  "msg": "计划路径中无1800站位",
  "message": "计划路径中无1800站位",
  "exceptionMsg": "",
  "excuteMiniSeconds": 32894,
  "env": "Production"
****}**
```
