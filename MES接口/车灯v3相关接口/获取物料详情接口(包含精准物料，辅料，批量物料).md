##### 获取物料详情接口(包含精准物料，辅料，批量物料)

简要描述

获取当前站位需要使用的精准物料详情，与后面“精准物料绑定接口”，“精准物料校验接口”联合使用

使用场景

在生产准备阶段调用该接口，显示需要上料的信息

请求URL：

测试：http://10.200.6.200:10002`/fundation``/api/device/get/all/material`

正式：http://10.200.6.27:10002`/fundation``/api/device/get/all/material`

webservice：

COM_Device_DeviceGetAllMat

请求方式

- POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID |String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**Body参数**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|planName|是|String|计划号||
|station|是|String|站位||
|line|是|String|线体||
|scanCode|是|String|扫描条码|可能是移动工装条码，可能是产品条码 如果是在准备阶段调用该接口，该字段可以传空|
|userCode|是|String|员工工号||
|pallet|否|String|托盘号|涉及固定工装站位使用该字段，其余不涉及固定工装不填该字段|

**返回参数说明**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|succ|否|Bool|接口状态||
|code|是|Int|错误码，0：成功；其他失败||
|msg|是|String|错误消息||
|exceptionMsg|否|String|异常信息||
|excuteMiniSeconds|否|Int|接口耗时||
|env |否|String|环境，development：开发环境，production：生产环境||
|data|是|String\[\]|精准物料信息||
|-matCode|是|String|物料代码||
|-matReplace|是|String|替代主物料||
|-matName|是|String|物料名称||
|-matUseNum|是|Double|物料用量||
|-matType|是|Int|物料类型 |0批量 1精准 接口返回为int类型，前端需要做转换，界面显示使用（批量、精准）等中文字样，|
|-matIsAccessories|是|Int|是否辅料|0否 1是 接口返回为int类型，前端需要做转换，界面显示使用（辅料、物料）等中文字样，|



**请求示例**

```JSON
{
  "planName": "ASM2512-037532",
  "station": "HUD004",
  "line": "ONT_DIP_007",
  "scanCode": "210264002510Q4100031",
  "userCode": "41487",
  "pallet": "GZ-QC-20255-JZJT-009VB"
}
```

**返回示例**

```JSON
{
  "succ": true,
  "code": 0,
  "msg": "",
  "exceptionMsg": "",
  "excuteMiniSeconds": 32379,
  "env": "Development",
  "data": [
  {"matCode": "3.KG.0041.2803",
  "matReplace": "3.KG.0041.2805",
  "matName": "集成电路",
  "matUseNum": 2,
  "matType": 1,
  "matIsAccessories": 0
  },
  {"matCode": "3.HW.0041.3804",
  "matReplace": "3.HW.0041.3805",
  "matName": "线圈",
  "matUseNum": 1,
  "matType": 1,
  "matIsAccessories": 0
  }
  ]
}
```

注意：若返回值无精准物料，则无需弹出精准物料框，若返回物料包含有精准物料，精准物料扫描框个数=精准物料个数\*物料用量，
