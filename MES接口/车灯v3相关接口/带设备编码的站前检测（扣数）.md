# 带设备编码的站前检测（扣数）

> **模块**: [[00-总览|MES接口]] > [[车灯v3相关接口/概览|车灯v3相关接口]]
> **方式**: POST

---

##### 带设备编码的站前检测（扣数）

**URL：**/before/ks/withdevicecode（完整路径见 Base URL）



**完整地址：**http://10.200.6.27:10002/fundation/api/online-mes/v2/transfer/before/ks/withdevicecode



**Method：**POST



**描述：**在指定站位进行站前检测，并携带设备编码。

**请求头（Headers）**

|参数名|类型|必填|说明|
|---|---|---|---|
|Content-Type|string|是|固定为 application/json|
|X-JZ-APPID|string|是|网关分配的应用ID（认证凭证）|

**请求体（Body）**

|参数名|类型|必填|说明|
|---|---|---|---|
|plan_name|string|是|计划名称，如 ASM2402-009527|
|station|string|是|站位编码，如 1800|
|line|string|是|线体编码，如 XT000012|
|codeSn|string|是|条码/序列号，如 123456|
|workStage|int|是|工段标识，如 2总装；1插件|
|deviceCode|string|是|设备编码|

**请求示例**





```JSON
{
  "plan_name": "ASM2502-022442",
  "station": "3MP2",
  "line": "XT000012",
  "codeSn": "LD248H110296",
  "workStage": 2,
  "deviceCode": "12345"
}
```

**响应示例**

成功时：

```JSON
{
    "data": {},
    "succ": true,
    "code": 0,
    "msg": "",
    "message": "",
    "exceptionMsg": "",
    "excuteMiniSeconds": 2330,
    "env": "Production"
}
```

失败时（如站位不在计划路径中）：

```JSON
**{**
**    "data": null,**
**    "succ": false,**
**    "code": 2,**
**    "msg": "R3263H250902有未审核完成的FA分析",**
**    "message": "R3263H250902有未审核完成的FA分析",**
**    "exceptionMsg": "",**
**    "excuteMiniSeconds": 8933,**
**    "env": "Production"**
**}**
```
