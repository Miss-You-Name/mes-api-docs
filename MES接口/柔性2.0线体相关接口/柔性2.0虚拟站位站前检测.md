##### **柔性2.0虚拟站位站前检测**

**简要描述**

获取该站位所有校验项

**请求URL：**

测试：http://10.200.6.200:10002`/fundation``/api/online-mes/v2/forward/rxv2/ss/checkallccdstation`

正式：http://10.200.6.27:10002`/fundation``/api/online-mes/v2/forward/rxv2/ss/checkallccdstation`



对应的websevice接口

StationService：RXV2_SS_CheckALLCCDStation

**请求方式**

POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID|String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**Body参数**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|planName|是|String|计划号||
|line|是|String|线体||
|scanCode|是|String|扫描条码|可能是移动工装条码，可能是产品条码|
|userCode|是|String|员工工号||
|backStation|是|string|上一站位|传递多少个站位，就校验多少个站位的CCD图片信息,按逗号进行分隔 例如：C001,S001,S002,S004|
|nowStation|是|string|当前站位||



**返回参数说明**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|code|int|错误代码|0：成功；1：失败|
|message|string|处理结果消息||
|data|string|结果数据|-|
|-pcbasn|string|产品条码||

|```JSON {   "planName": "ASM2505-026189-test",   "line": "ONT_DIP_007",   "scanCode":"GZ-QG-20259-JZJT-021VA",   "userCode": "41487",   "backStation":"CH-DY",   "nowStation":"CH-1" } ``` |
