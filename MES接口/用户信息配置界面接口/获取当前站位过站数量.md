##### **获取当前站位过站数量**

根据计划和站位查询计划过该站位的条码数，数据来源（数据湖）

**请求URL**

- `测试环境 ``http://10.200.6.200:10002/fundation/api/doris/count/station`

- `正式环境 ``http://10.200.6.27:10002/fundation/api/doris/count/station`

**请求方式**

POST

**请求参数说明获取过站结果信息**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID|String|网关分配的应用Id |设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**Body参数**

|**参数名**|必选|**类型**|**备注**|
|---|---|---|---|
|planName|是|string|计划号|
|station|是|string|站位|



**返回参数说明**



|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|code|int|code代码不为0是需要弹出message|0：成功；1：失败|
|message|string|错误信息|-|
|data|int|过站数||



**请求成功示例**

```Plain Text
{
    "planName": "PCB2512-045459",
    "station": "S005"
}
```



**返回示例**

```JSON
{
  "data": 9200,
  "succ": true,
  "code": 0,
  "msg": "",
  "message": "",
  "exceptionMsg": "",
  "excuteMiniSeconds": 201,
  "env": "Production"
}
```
