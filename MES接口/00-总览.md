| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | int | 错误代码，0：成功；非0：失败 |
| message | string | 处理结果消息 |
| succ | bool | true：成功；false：失败 |
| exceptionMsg | string | 异常信息 |
| excuteMiniSeconds | long | 执行耗时（毫秒） |
