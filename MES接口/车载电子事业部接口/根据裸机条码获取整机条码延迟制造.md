##### 根据裸机条码获取整机条码 【延迟制造】

简要描述

根据裸机条码获取整机条码

接口涉及项目：VIU 

请求URL

- `http://10.200.6.27:10002/fundation/online-mes/``ml/ss/cz/getproductcodewithcode`

请求方式

- POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID|String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**Body参数**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|codeSn|是|string|裸机条码|-延迟制造才有裸机与整机条码关系|

**返回参数说明**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|code|int|错误码|0：成功，其他失败|
|message|string|错误信息|-|
|data|string|条码||

**请求示例**

```JSON
{
    "codeSn":"R3254H313542"
}
```

**返回成功示例**

```JSON
{
  "data": "R3255H013355",
  "succ": true,
  "code": 0,
  "msg": "",
  "exceptionMsg": "",
  "excuteMiniSeconds": 797,
  "env": "Development"
}
```
