##### 修改条码状态【镭雕】

简要描述

修改条码状态，镭雕成功，不会取这个条码

**请求URL**

- `http://10.200.6.27:10002/fundation/online-mes/``ml/ss/dy/laseruploadresult`

**请求方式**

POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID|String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**Body参数**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|planName|是|string|计划号||
|laserName|是|string|设备号||
|codeSns|是|string|条码|codeSns:以,号分隔|
|result|是|int  |1 标识镭雕成功||

**返回参数说明**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|code|int|错误码|0：成功，其他失败|
|msg|string|错误信息|-|

**请求示例**

```JSON
{
    "planName":"ASM2410-017092",
    "laserName":"device",
    "codeSns":"",
    "result":1
}
```

**返回成功示例**

```JSON
{
  "succ": true,
  "code": 1,
  "msg": "",
  "exceptionMsg": "",
  "excuteMiniSeconds": 99,
  "env": "Development"
}
```
