##### **柔性2.0获取当前站位对应的校验项**

**简要描述**

获取该站位所有校验项

**请求URL：**

测试：http://10.200.6.200:10002`/fundation``/api/online-mes/v2/forward/rxv2/ss/getstationcheck`

正式：http://10.200.6.27:10002`/fundation``/api/online-mes/v2/forward/rxv2/ss/getstationcheck`

对应的websevice接口

StationService：RXV2_SS_GetStationCheck

**请求方式**

POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID|String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**Body参数**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|planName|是|String|计划号||
|station|是|String|站位||
|line|是|String|线体||
|userCode|是|String|员工工号||



**返回参数说明**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|code|int|错误代码|0：成功；1：失败|
|message|string|处理结果消息||
|data|string|结果数据|-|
|-codeName|string|校验项名|流水21条码，彩盒条码|
|-codeType|string|校验项代码|例如：BarCode21,BarCodeColorBox等等|
|-codeValue|string|校验值|系统中配置的校验项值|

**请求成功示例**

|```JSON {   "planName": "ASM2505-026189-test",   "station": "CH-3",   "line": "ONT_DIP_007",   "userCode": "41487" } ``` |
|---|

**返回示例**

|```JSON {     "data": [{"codeName":"铭牌21条码","codeType":"BarCode21_Nameplate","codeValue":"BarCode21_Nameplate"},     {"codeName":"其他条码","codeType":"BarCodeQT","codeValue":"BarCodeQT"},     {"codeName":"进网条码SN2","codeType":"BarCodeInterSN2","codeValue":"BarCodeInterSN2"},     {"codeName":"说明书","codeType":"BarCodeInstruction","codeValue":"BarCodeInstruction"}],     "succ": **true**,     "code": 0,     "msg": "",     "message": "",     "exceptionMsg": "",     "excuteMiniSeconds": 6,     "env": "Development" } ``` |
|---|
