##### **柔性2.0ATE测试装备过站状态查询**

**简要描述**

此接口用于统一MES的过站查询

**请求URL：**

`http://10.200.6.27:10002/mes/api/station/resultlist/get/v1.0.0`

对应的websevice接口

http://10.200.6.54:10002/StationService.asmx?op=ML_SS_MESStationInfo

**请求方式**

POST

**请求参数说明**

**Header参数**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|X-JZ-APPID|String|网关分配的应用Id|设备统一用【c7a8830e352047fdba14ff2f4030b09e】|

**Body参数**

|**参数名**|**必选**|**类型**|**说明**|**备注**|
|---|---|---|---|---|
|procssCode|是|string|工序||
|siteCode|是|string|工位||
|snList|是|list|条码列表|-|



**返回参数说明**

|**参数名**|**类型**|**说明**|**备注**|
|---|---|---|---|
|code|int|错误代码|0：成功；1：失败|
|message|string|处理结果消息||
|data|string|结果数据|-|

**请求成功示例**

|```JSON {   "procssCode": "FT2",   "siteCode": "MP14",   "snList": [     "LD25CH806561"   ] } ``` |
|---|

**返回示例**

|```JSON {   "code": 0,                //错误码，0说明请求正常   "message": "",            //返回消息说明，可默认空   "status": 200,            //请求状态码   "data": "[{\"plan_name\":\"PCB2512-045531\",\"station\":\"1MP14\",\"result\":0,\"msg\":\"测试成功，请到下一站（9990）测试！\",\"create_time\":\"2026-01-21T11:11:17.519855\",\"pcbasn\":\"LD25CH806561\"}]", } 备注：data中数据描述 //plan_name 计划号 //station 站位 //result 测试状态, 0：成功/1：失败/2：提醒 //msg 过站信息，“测试成功...” / “测试失败...” / “本次测试失败，需在本工序【3MP1】再测试成功1次才能流入下一工序！” //create_time 过站数据创建时间 //pcbasn 单板SN ``` |
|---|
